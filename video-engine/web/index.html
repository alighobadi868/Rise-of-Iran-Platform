موتور مستقل تولید فیلم

متن فارسی را وارد کن؛ موتور آن را به صحنه‌های تصویری تبدیل می‌کند و یک فایل MP4 قابل دانلود می‌سازد. برای این نسخه به API هوش مصنوعی پولی نیاز نیست.

نسخهٔ اولیه از کارت‌های تصویری و زیرنویس استفاده می‌کند؛ هنوز فوتیج واقعی تولیدشده با مدل ویدئویی یا گویندگی خودکار ندارد. فایل‌ها ممکن است با پاک‌شدن فضای موقت سرور حذف شوند؛ دانلود را پس از ساخت انجام بده.
